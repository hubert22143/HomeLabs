Part 1 - Initial Setup

1. Set the correct hostname on every router and switch.
2. Configure the enable secret as user on every router and switch. Use type 9 hashing if supported; otherwise, use type 5.
3. Create a local user account named admin with the password password on every router and switch. Use type 9 hashing if supported; otherwise, use type 5.
4. Configure the console line to authenticate using the local user database. Set the inactivity timeout to 30 minutes and enable synchronous logging.

Part 2 - VLANs and Layer-2 EtherChannel

1. In Office A, configure Layer-2 EtherChannel PortChannel1 between DSW-A1 and DSW-A2 using a Cisco-proprietary protocol. Both switches should actively attempt to form the EtherChannel.
2. In Office B, configure Layer-2 EtherChannel PortChannel1 between DSW-B1 and DSW-B2 using an open standard protocol. Both switches should actively attempt to form the EtherChannel.
3. Configure all Access-to-Distribution links, including EtherChannels, as trunk links.
   a. Disable DTP explicitly on every trunk port.
   b. Set the native VLAN on each trunk to unused VLAN 1000.
   c. In Office A, allow VLANs 10, 20, 40, and 99 on all trunks.
   d. In Office B, allow VLANs 10, 20, 30, and 99 on all trunks.
4. Configure one Distribution switch in each office as a VTPv2 server using the domain name NetworkLab.
   a. Confirm that the other switches join the VTP domain.
   b. Configure all Access switches as VTP clients.
5. In Office A, create and name these VLANs on one Distribution switch, then verify that VTP shares the changes:
   a. VLAN 10: PCs
   b. VLAN 20: Phones
   c. VLAN 40: Wi-Fi
   d. VLAN 99: Management
6. In Office B, create and name these VLANs on one Distribution switch, then verify that VTP shares the changes:
   a. VLAN 10: PCs
   b. VLAN 20: Phones
   c. VLAN 30: Servers
   d. VLAN 99: Management
7. Configure each Access switch access port.
   a. LWAPs should not use FlexConnect.
   b. Place PCs in VLAN 10 and phones in VLAN 20.
   c. Place SRV1 in VLAN 30.
   d. Manually configure access mode and explicitly disable DTP.
8. Configure the ASW-A1 link to WLC1.
   a. The link must carry both the Wi-Fi and Management VLANs.
   b. The Management VLAN should be untagged.
   c. Disable DTP.
9. Administratively shut down all unused ports on Access and Distribution switches.

Part 4 - Rapid Spanning Tree Protocol

1. Enable Rapid PVST+ on every Access and Distribution switch.
   a. Match each VLAN’s Root Bridge to its HSRP Active router by using the lowest possible STP priority.
   b. Set the HSRP Standby router for each VLAN to the next STP priority increment above the lowest value.
2. Enable PortFast and BPDU Guard on all end-host-facing ports, including the WLC1 connection. Apply these settings in interface configuration mode.

Part 5 - Static and Dynamic Routing

1. Configure OSPF on R1’s LAN-facing interfaces and on all Layer-3 interfaces of Core and Distribution switches.
   a. Use process ID 1 and Area 0.
   b. Set each router ID manually to match the device’s loopback IP address.
   c. On switches, use network commands that match each interface IP exactly.
   d. On R1, enable OSPF directly under interface configuration mode.
   e. Enable OSPF on all loopback interfaces and make loopbacks passive.
   f. Make each Distribution switch SVI passive, except the Management VLAN SVI.
   g. Configure physical OSPF neighbor links to use a network type that does not elect a DR or BDR. Leave the CSW1/CSW2 Layer-3 PortChannel interfaces at their default network type.
2. Configure one recursive static default route for each R1 Internet connection.
   a. Make the route through G0/1/0 a floating static route by setting its AD to 1 above the default.
   b. Configure R1 as an OSPF ASBR so it advertises its default route into the OSPF domain.

   d. Test Internet failover by disabling R1 G0/0/0 and pinging again.
      i. In Packet Tracer, remove and reapply the OSPF default-information originate command for failover testing.
      ii. Re-enable G0/0/0, then remove and reapply default-information originate again.
13. Disable CDP on all devices and enable LLDP.
   a. Disable LLDP transmission on each Access switch F0/1 access port.

Part 7 - Security: ACLs and Layer-2 Security Features

1. Configure extended ACL OfficeA_to_OfficeB in the correct location.
   a. Permit ICMP from the Office A PC subnet to the Office B PC subnet.
   b. Deny all other traffic from the Office A PC subnet to the Office B PC subnet.
   c. Permit all remaining traffic.
   d. Apply the extended ACL according to standard best practice.
2. Configure Port Security on each Access switch F0/1 port.
   a. Allow only the minimum required number of MAC addresses.
      i. SRV1 does not use virtualization, so it requires only one MAC address.
   b. Use a violation mode that blocks invalid traffic while allowing valid traffic to continue. The switches should generate notifications when invalid traffic is detected.
   c. Configure the switches to automatically save learned secure MAC addresses to the running configuration.
3. Configure DHCP Snooping on all Access switches.
   a. Enable DHCP Snooping for all active VLANs in each LAN.
   b. Trust the appropriate ports.
   c. Disable DHCP Option 82 insertion.
   d. Set a DHCP rate limit of 15 packets per second on active untrusted ports.
   e. Set a higher limit of 100 packets per second on ASW-A1’s connection to WLC1.
4. Configure Dynamic ARP Inspection on all Access switches.
   a. Enable it for all active VLANs in each LAN.
   b. Trust the appropriate ports.
   c. Enable all optional validation checks.

Part 8 - IPv6

1. Enable IPv6 routing and configure IPv6 addresses on R1, CSW1, and CSW2 to prepare for IPv6 migration.
   a. R1 G0/0/0: 2001:db8:a::2/64
   b. R1 G0/1/0: 2001:db8:b::2/64
   c. R1 G0/0 and CSW1 G1/0/1: Use prefix 2001:db8:a1::/64 with EUI-64 interface IDs.
   d. R1 G0/1 and CSW2 G1/0/1: Use prefix 2001:db8:a2::/64 with EUI-64 interface IDs.
   e. CSW1 Po1 and CSW2 Po1: Enable IPv6 without using the ipv6 address command.
2. Configure two IPv6 default static routes on R1.
   a. Add a recursive route through next hop 2001:db8:a::1.
   b. Add a fully specified route through next hop 2001:db8:b::1, and make it floating by setting the AD 1 higher than default.
